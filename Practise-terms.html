Href attribute

The <a> tag defines a hyperlink. The Href attribute specifies the url of the page that it goes to:

Example: <a href="https://www.google.com">Google</a>

Src Attributes

The <img> is used to embed an image into an HTML page. The src attribute specifies the path to the image being displayed:

<img src="lexus.jpeg">

There are two ways to specify the URL in the src attribute:

1. Absolute URL - links to an external image that is hosted on another website. Example: src="https://www.w3schools.com/images/img_girl.jpeg"

Relative URL - Links to an image that is hosted within the website. Here, the URL does not include the domain name. If the URL begins without a slash, it will be relative to the current page. Example:src="img_girl.jpg". If the URL begins with with a slash, it will be relative to the domain. Example:src="/images/img_girl.jpg"

Tip: It is almost always best to use relative URLs. They will not break if you change domain.

The required alt attribute for the <img> specifies an alternate text for an image, if the image for some reason can not be displayed.This can be due to a slow connection, or an error in the src attribute, or in the users screen reader.

<img src="lexus.jpeg" alt="White lexus is250">

HTML Paragraphs

A paragraph always start on a new line, and is ususally a block of text.

The HTML <p> element defines a paragraph.

  • Horizontal Rules The <hr> tag defines a thematic break in a HTML page, and is most often displayed as a horizontal rule. It is used to seperate content in a html page.
  • Line Breaks The <br> element defines a line break. This is mainly used when wanting to break a line without starting a new p tag.
  • Both do not need a closing tag

HTML Styles

The HTML style attribute is used to add styles to an element, such as font, coloer, size and more.

The HTML Styles Attribute

Setting the style of an HTML element, can be done with the styles attribute.

The HTML style attribute has the following syntax:

<tagname style="property:value;">

Background Color

The CSS background-color property defines the background color for an HTML element.

Example: set background color for two different types of elements.

  • <h1 style="background-color: green">This is a heading</h1>

    • This is a heading

  • <p style="background-color: lightgray">This is a paragraph</p>

    • This is a paragraph

Text Color

The CSS color property defines the text color for an HTML element:

Example:

  • <h1 style="color: green;">This is a heading</h1>

    • This is a heading

  • <p style="color: red">This is a paragraph.</p>

    • This is a paragraph.

Fonts

The CSS font-family property defines the font to be used for an HTMl element:

Example:

  • <h1 style="font-family: veradna;">This is a heading</h1>

    • This is a heading

  • <p style="font-family: "courier new";">This is a paragraph.</p>

    • This is a paragraph.

Text Alignment

The CSS text-align property defines the horizontal alignment for an HTML element:

Example:

  • <h1 style="text-align: center;">This is a heading</h1>

    • This is a heading

  • <p style="text-align: center;">This is a paragraph.</p>

    • This is a paragraph.

HTML Text Formatting

HTML contains several elements for defining text with a special meaning.

Formatting elements were designed to display special types of text:

  • <b> - Bold Text
  • <strong> - Important Text
  • <i> - Italic Text
  • <em> - Emphasized Text
  • <mark> - Marked Text
  • <small> - Small Text
  • <del> - Deleted Text
  • <ins> - Inserted Text
  • <sub> - Subscript Text
  • <sup> - Superscript Text

HTML Quotation and Citations Elements

HTML <blockquote> for Quotations

The HTML <blockquote> element defines a section that is quoted from another source.

Browsers usually indent <blockquote> elements.

Example:

Lorem ipsum dolor sit amet, consectetur adipisicing elit. Assumenda accusamus, temporibus, possimus eos aliquam repudiandae adipisci placeat sit, debitis magnam facere quas molestiae deserunt. Natus ullam error dolor veritatis laborum!

HTML <q> for Short Quotations

The HTML <q> element defines a short quotation.

The W3C's mission is to promote the widespread use and development of the Web.

HTML <abbr> for Abbreviations

The HTML <abbr> element defines an abbreviation or an acronym.

The <abbr> element has a required title attribute, which defines the full term for the abbreviation.

Example:

The <abbr title="World Health Organization">WHO</abbr> was founded in 1948.
