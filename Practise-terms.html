Href attribute

The <a> tag defines a hyperlink. The Href attribute specifies the url of the page that it goes to:

Example: <a href="https://www.google.com">Google</a>

Google

Src Attributes

The <img> is used to embed an image into an HTML page. The src attribute specifies the path to the image being displayed:

<img src="lexus.jpeg">

There are two ways to specify the URL in the src attribute:

1. Absolute URL - links to an external image that is hosted on another website. Example: src="https://www.w3schools.com/images/img_girl.jpeg"

Relative URL - Links to an image that is hosted within the website. Here, the URL does not include the domain name. If the URL begins without a slash, it will be relative to the current page. Example:src="img_girl.jpg". If the URL begins with with a slash, it will be relative to the domain. Example:src="/images/img_girl.jpg"

Tip: It is almost always best to use relative URLs. They will not break if you change domain.

The required alt attribute for the <img> specifies an alternate text for an image, if the image for some reason can not be displayed.This can be due to a slow connection, or an error in the src attribute, or in the users screen reader.

<img src="lexus.jpeg" alt="White lexus is250">

The Style Attribute

The style attribute is used to add styles to an element, such as color, font and size.

<p style="color: red">This is a red paragraph.<p>

This is a red paragraph.
